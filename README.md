# YVIMO Web

First full-code version of the YVIMO website.

## Focus

- YVIMO as a company brand.
- Industrial Automation as one business line.
- Software Services as a new business line.
- YVIMO products, starting with YVIMO Gateway.
- Future platform foundation for accounts, APIs, and licensing.

## Commands

```bash
npm install
npm run dev
npm run build
```
